# 📊 Panel de ventas – Power BI

Dashboard interactivo desarrollado en Power BI para el análisis de ventas, enfocado en evaluar el desempeño comercial y apoyar la toma de decisiones.

🔗 **Archivo Power BI (.pbix) y capturas del dashboard:**  
https://drive.google.com/drive/folders/1ene8dMRxoa7jJw4me3HQuBmchQrC4af7?usp=sharing 

---

## 🎯 Objetivo del proyecto
Analizar el desempeño comercial y facilitar la toma de decisiones mediante el uso de indicadores clave (KPIs) y visualizaciones dinámicas.

---

## 📌 KPI principales
- Ventas totales  
- Ganancia total  
- Margen de ganancia (%)  

---

## 📊 Análisis de resultados
- Ventas por categoría y segmento  
- Ventas por subcategoría  
- Tendencia mensual de ventas  
- Filtro temporal por fecha de orden  

---

## 🛠️ Herramientas utilizadas
- Power BI Desktop  
- DAX  
- Modelado de datos  

---

## 📷 Vista del Dashboard
Las capturas del panel se encuentran disponibles en la carpeta **/screenshots**, donde se visualizan los principales indicadores y análisis desarrollados.
